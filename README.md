# AxxistSteam Releases

Öffentliche Download- und Update-Quelle für **AxxistSteam** – den Steam-Account- und Idling-Manager.

Dieses Repository enthält **keine** Quelltexte – nur:

- 📦 **Installationspakete** für jede Version (Windows `.exe`, Linux `.deb` / AppImage) unter [Releases](../../releases)
- 🔄 **`latest.json`** – das Update-Manifest, das die App für die automatische Update-Erkennung abfragt
- 📝 **Release Notes** – alle Änderungen pro Version

## Download

Die aktuelle Version findest du immer unter [**Neueste Version**](../../releases/latest).

| Plattform | Datei |
|-----------|-------|
| Windows   | `*_x64-setup.exe` |
| Linux     | `*_amd64.deb` oder AppImage |

## Updates

Die App prüft automatisch im Hintergrund, ob eine neue Version verfügbar ist, und zeigt sie in den
Benachrichtigungen sowie unter **Einstellungen → Updates** an. Von dort aus kannst du das Update
per Klick installieren (Windows/AppImage) oder das Paket manuell herunterladen (deb).

## Lizenz

AxxistSteam ist proprietäre Software – siehe die `LICENSE`-Datei im Installationspaket.
