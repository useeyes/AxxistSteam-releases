# Contributing to AxxistSteam

Thank you for your interest in improving AxxistSteam! 🎉

The AxxistSteam **source code is private** - this repository is the public distribution point
(installers, update manifests, documentation). But there are still meaningful ways to contribute:

## 🐛 Report bugs

Open a [bug report](../../issues/new?template=bug_report.yml) and include:

- Your OS and AxxistSteam version (visible in **Settings → Updates**)
- What you did, what you expected, what happened
- Relevant log output if possible

## 💡 Suggest features

Open a [feature request](../../issues/new?template=feature_request.yml) or discuss it first on
[Discord](https://discord.gg/k3fara4U64). The roadmap in the [README](../README.md) shows what's
already planned.

## 📝 Improve documentation

The docs in [`docs/`](docs/) live in this repository - typos, unclear steps, missing platform
notes? Pull requests are welcome.

## 🌍 Translations

AxxistSteam is translated into 10 languages. Want to fix a translation or add a language? Open an
issue and we'll get you set up.

## Ground rules

- Be respectful - see the [Code of Conduct](CODE_OF_CONDUCT.md)
- Don't attach or link to AxxistSteam's private source code anywhere
- Don't upload builds you made yourself to the releases - only maintainers publish releases
